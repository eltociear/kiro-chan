# Kiro-Chan

Your coding buddy that reacts to your code! Rainbow vibes when you're in the zone, turns RED when bugs appear. Never code alone again.

## Features

- Cute animated Kiro character in the status bar
- **Rainbow Mode** - Endless color cycling animation
- **Real-time Error Detection** - Background turns red when your code has errors
- Reacts to your typing with animations
- Task completion notifications

## Settings

| Setting | Default | Description |
|---------|---------|-------------|
| `kiro-chan.enabled` | `true` | Show/hide the character |
| `kiro-chan.displayColor` | `#FFFFFF` | Character and text display color |
| `kiro-chan.rainbowMode` | `false` | Enable rainbow color animation |
| `kiro-chan.rainbowSpeed` | `50` | Rainbow color change speed (ms) |
| `kiro-chan.diagnosticsEnabled` | `true` | Show red background when errors exist |
| `kiro-chan.notificationEnabled` | `true` | Enable task completion notifications |
| `kiro-chan.soundEnabled` | `true` | Enable notification sound |
| `kiro-chan.soundVolume` | `0.5` | Sound volume (0.0-1.0) |
| `kiro-chan.animationSpeed` | `1` | Animation speed multiplier |

## Commands

- `Kiro Chan: Toggle Kiro Character` - Toggle visibility

## Installation

1. Download the `.vsix` file
2. Run `Extensions: Install from VSIX...` in VS Code
3. Select the downloaded file
